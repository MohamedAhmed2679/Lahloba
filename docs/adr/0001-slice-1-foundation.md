# ADR 0001 — Slice 1 foundation choices

- **Status:** Accepted for development; revisit before production.
- **Date:** 2026-10-23
- **Context:** Blueprint doc 05 recommends a TypeScript monorepo, Expo clients, a protected ops web,
  a modular backend, PostgreSQL with geospatial support, private media storage and outbox workers,
  with versions confirmed from official sources and pinned.

## Decisions

| # | Decision | Why | Consequence / revisit |
|---|---|---|---|
| 1 | **pnpm 10 workspace, `nodeLinker: hoisted`** | Expo/Metro resolves native modules reliably with a hoisted layout | Lockfile generated by pnpm (`pnpm-lock.yaml`), not hand-written |
| 2 | **Expo SDK 58** (`expo 58.0.17`, RN 0.88.0, React 19.3.0, expo-router 58.0.25) | Versions taken from Expo's `bundledNativeModules.json` for SDK 58 so native modules match | Upgrade by SDK, not package by package |
| 3 | **TypeScript 6.0.3, not 7.0** *(deviation)* | npm `latest` is 7.0.2 (native compiler), but Expo SDK 58's template pins `~6.0.3`; staying aligned avoids tooling breakage | Re-evaluate when Expo adopts TS 7 |
| 4 | **Fastify 5 + `pg` with hand-written SQL**, no ORM | Transactional rules (locks, SKIP LOCKED, triggers, idempotency) are explicit and reviewable | More SQL to maintain; repositories can be extracted per module later |
| 5 | **Plain SQL migrations with up/down files and checksums** | Reviewable DDL, triggers and checks; runner refuses edited applied migrations; advisory lock serializes migrators | Rollback is refused in staging/production by the CLI (use the recovery runbook) |
| 6 | **Area-based serviceability; PostGIS deferred** *(deviation)* | Distance bands and tariffs are unresolved founder decisions; manual area entry is a requirement anyway. PostGIS was not available in the verification environment | `private_addresses` stores optional lat/lng; add PostGIS + route eligibility with Slice 2 quotes |
| 7 | **Identity: provider-neutral OIDC/JWKS adapter + dev stub behind an explicit flag** | Provider not chosen yet. Config fails closed: dev stub refused outside development/test, requires `LAHLOBA_DEV_IDENTITY_STUB=true` and a 32+ char secret; dev subjects are namespaced `dev:` | Client-side OIDC (auth code + PKCE) is not implemented; partner/ops apps only offer dev sign-in |
| 8 | **Authorization: scoped memberships in DB + pure policy functions + per-route checks**; inaccessible scoped resources return 404 | Avoids existence leaks; UI gating is cosmetic only | Postgres RLS not enabled yet (doc 05 notes RLS is defence-in-depth, not a substitute) |
| 9 | **Public responses serialized through zod contract schemas** | Unknown keys are stripped, so a query that selects a private column cannot leak it | Contracts must be updated deliberately when public fields change |
| 10 | **Idempotency in the same DB transaction as the mutation** (PK on actor+route+key) | Concurrent duplicates serialize on the PK; failed operations roll back their record | Records expire after 24 h (cleanup job not yet scheduled) |
| 11 | **Transactional outbox + worker with leases and dead-letter** | Doc 05 §5.4; handlers run outside locks | Delivery is at-least-once: handlers must stay idempotent |
| 12 | **Operations console as a separate Vite + React web app** | Must be a protected, separate surface; simpler than Expo for dense desktop UI | Hosting/auth hardening (SSO, IP allow-lists) pending |
| 13 | **UI tests via react-native-web in jsdom (Vitest)** | Fast, runs in CI without simulators | Native rendering, screen readers and device font scaling are NOT verified by these tests |
| 14 | **Neutral replaceable tokens; placeholder app names/bundle IDs** | Branding is deferred (blueprint rule 17) | `packages/ui/src/tokens.ts` and `app.json` identifiers must change before store submission |
| 15 | **Evidence storage port with two non-production modes** (`disabled`, `dev-metadata-only`) | No storage provider chosen; never pretend a file was uploaded | Approval requires ≥1 evidence reference, but reviewers cannot view files yet |

## Ported starter invariants

`starter/domain.mjs` was ported to `packages/domain` with types (money, packs, quotes, fulfillment
guards); its 32 behaviours are covered by `packages/domain/src/domain.test.ts`. Quote endpoints are
intentionally not exposed until Slice 2.
